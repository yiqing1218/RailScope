# 中国动车组参考数据快照

`reference.json` 保存从 [中国动车组](https://china-emu.cn/RailRoads/)取得的线路、车站与具体车型参考属性。`coverage.json` 为本次只读底图匹配报告；名称候选不等同于已经核验的业务关联。

每份资料保留原始页面 URL、获取时间、页面 SHA-256、适用区段/站场、未核验状态和来源声明。字段名经过规范化，部分范围被拆成独立 scopes；参数条件和站台编号按来源保存。未成功读取的页面保存在 `errors` 中。未提交网页 HTML、照片、插画、页面样式或原始 OSM/GIS 数据。

来源与署名：中国动车组 china-emu.cn / 慧伊创新科技（北京）有限公司。参考数据为非官方资料，不构成调度进路或实际运行状态认定。

本目录的来源数据依据网站[使用协议与版权信息](https://china-emu.cn/About/Agreement/)使用，一般遵循 **CC BY-NC-SA 3.0 中国大陆**；网站禁止商业使用。公开再分发时保留来源及许可说明，并遵守同方式共享等要求。此声明只适用于来源数据，不改变 RailScope 代码的许可。
