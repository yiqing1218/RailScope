# 实体、显示与导出更新

统一使用 `railscope.domain`。源几何留在导入库，实体引用稳定 ID；用户名称、速度、颜色和编号持久保存到工作区。地图几何、目录、标注和导出使用同一实体身份。

- ServiceArea 关联 POI、AOI 和建筑；选择、修改和显示开关按服务区实体传播。
- InfrastructureLine 的类别、设计速度、建设状态独立；可见线路集合决定其几何、文字及关联点的显示。共享点只需一个所属线路可见。
- StationTrack 保存名称、编号和有向物理区间引用；自动编号只在创建/整理时写入，人工修改优先。站场图由这些对象和真实拓扑生成。
- Corridor 增加正式颜色属性，旧数据默认 `#466979`；桌面 DTO、导入导出和领域适配器一致。
- 高质量地图导出采用独立高像素渲染器，复用当前相机、数据和样式；站场图独立输出二维矢量图，不使用底图截图。
- 地图查询在预算截断之前排除隐藏线路及隐藏建设状态，避免隐藏对象占用可见对象的加载额度。

验证针对实体一致性、共享节点可见性、旧数据兼容、持久化往返、导出尺寸及实际线路数据进行。

## 使用入口

| 功能 | 入口 |
| --- | --- |
| 服务区统一名称和属性 | 选择点、边界或建筑 → 编辑对象信息；目录搜索共用名称 |
| 线路名称开关 | 编辑 → 显示线路名称 |
| 设计速度 | 选中线路 → 编辑对象信息 → 设计速度（km/h） |
| 四档高速样式及更多线型 | 显示 → 线路显示样式 → 国铁线路样式；350 / 250 / 200 / 160 分别设置 |
| 高清地图 | 文件 → 当前页面高质量导出；保持当前视窗比例、范围和可见样式，PNG 300 DPI |
| 站场示意图 | 选择车站或已关联站场股道 → 文件 → 一键导出所选站场示意图；SVG / PDF / PNG |
| 股道命名和编号 | 编辑 → 站场股道命名 / 自动编号；选中具体股道后编辑会定位对应行 |
| 股道搜索 | 股道管理窗口搜索；保存为实体后也可通过顶栏“站场股道”搜索并定位 |
| 通道颜色 | 编辑通道 → 通道颜色；随计划和通道 JSON / CSV 保存 |

股道使用共享 `StationTrack`，以稳定 `TRK-*` ID 引用真实 `NE-*` 边。已有 RS 名称记录在载入时适配为实体；工作区保存实体字段和兼容显示投影。源编号相同且共享真实端点的区间合为一根股道，不按距离或同名强行连接。源编号和手工名称优先；自动编号为暂编，不能当作官方股道号。无法安全重绑的旧物理引用会明确报出迁移问题。

服务区保留原始 source 成员。唯一源 AOI 内的服务区 POI 作为同一实体的表现形式；旧 POI override 经别名重放到 AOI 实体。原始服务区记录和几何不删除。几何之间的关联是自动参考，不是权属认定。

设计速度不借用运营 `maxspeed`，未提供设计速度时仍用高速默认样式。在建线使用独立虚线规则，颜色沿用类型及速度档。

## 导出验证

独立 Qt WebEngine / MapLibre 画布实测：800×500 CSS 视窗（屏幕画布 1200 px 宽）输出 4000×2500 PNG，导出前后地理范围完全一致。导出复用当前源数据、相机、样式和可见性；独立加载底图瓦片，不改变原地图尺寸。受显卡画布上限约束时明确提示降低输出尺寸。

上海虹桥站真实数据已生成 `data/logs/hongqiao-station.svg` 与 PNG 预览，包含真实轨道、拓扑岔接点、平台轮廓及股道文字。图面按主轴旋转，横纵比例单独调整；不会生成不存在的连接、站台或调度进路。
