# 底图与专题显示责任

| 视觉源 | 显示职责 |
| --- | --- |
| 地理底图 | 普通道路、水系、绿地、行政边界、普通建筑、地名。低 Zoom 使用预切图层，高 Zoom 读取快照地理要素 |
| 交通专题 | 国铁、地铁、高速、交通站名、道岔和站场设施。底图分类排除 `motorway` 主线和匝道 |
| 动态图层 | 所选对象和完整几何、运行参考路径、批量列车状态 |

工作台「视图」提供专业浅色、常规彩色、深色、纯交通。WebView 使用本机字体，矢量样式资源随程序或包提供。切换主题沿用相机和工作区设置。卫星和按需联网在界面明确标为不可用，当前没有获授权可用的来源配置。

快照保存 `colour` 原值与来源的关系 ID。可追溯且唯一的 OSM route master 优先于子 route，缺少颜色时使用类别样式。相同物理轨道承载多条线路时以并排带区分，工作区可覆盖线路颜色。站台和站房来自相应源几何，源对象缺失时保留其可查证的点或线，站台面积用真实闭合几何或完整 multipolygon 关系表达。[OpenStreetMap 署名与许可](https://www.openstreetmap.org/copyright)
