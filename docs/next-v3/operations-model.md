# 运行数据和模拟

在「运行」中从地图或目录选中运营轨道，设为通道起止，选择自动参考或严格唯一。自动参考结果保存具体边序列，可对顺序与方向手工纠正。选择已核验需要提供来源和核验人，工作台保存用户给出的证据。严格模式发现多条合法路径时等待人工裁决。

服务用于车次名称和类别，日期化运行引用固定通道版本、停站或通过时刻和显式停站锚点。车种、车组、分配独立维护。导入支持 CSV、JSON 和 GTFS ZIP，GTFS 通过 `stop_id` 映射到已知 RailScope 站点。若无物理通道，导入时刻可用于计划视图。L2 路径要求连续有向边、运营状态和明确停站锚点。运行时刻可跨午夜，所有采样以同一运营日时钟为准。

- **L1 计划**展示日期化时刻和停站，缺少物理路径时保留未知位置。
- **L2 路径仿真**在物理轨道上按距离插值，用加减速和限速计算位置，支持暂停、跳转、倍率和跟随。地铁运行限上海快照。
- **L3 假设场景**检查资源占用、同向间隔、对向占用和车辆周转，支持延误参数与诊断。场景规则为假设，实际信号联锁和调度数据无已核验输入。

工作台示例使用用户选中的通道，站点锚点和时刻用于演示。真实平台编号、站内联锁进路和列车车组须有依据。GTFS 几何和时刻也不能用于自动创建正式轨道径路。[GTFS 规范](https://gtfs.org/documentation/schedule/reference/)
