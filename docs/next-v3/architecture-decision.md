# ADR 01 保留 Tauri 和 MapLibre，增加本地高缩放瓦片

## 决策

保留 Tauri 2、React、MapLibre、Rust 和 PMTiles。低缩放保留已有归档，源精度模式的更高缩放按可视 XYZ 查询快照 SQLite 的 RTree，裁切 WGS84 几何后量化为 MVT。以当前快照和瓦片坐标为缓存键，分别维护进程内缓存与有预算的本地 SQLite 缓存。发现超预算瓦片时返回明确错误。

## 对照

用同一全国库比较 Z8 归档在 Z12.9 的显示与新 Z12 瓦片。原生瓦片在同一对照片段保留了 42 个源顶点，最大偏差约 0.069 像素，原包相对应的结果是 4 个和 7.397 像素。这个对照把问题定位在源访问和切片分配。Qt 或 MapLibre Native 的同机对照未执行。[MVT 规范](https://mapbox.github.io/vector-tile-spec/)

## 边界

每个地图只激活一个快照。从全国包放大可继续读取同一全国库的明细。独立区域包通过数据菜单切换，当前没有跨快照的空间拼接和自动区域替换。保留单快照约束可使每个瓦片渲染 ID 始终使用对应快照解码。
