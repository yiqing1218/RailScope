# 工作台使用说明

1. 安装 Windows x64 程序，双击仓库的 `Start-RailScope.cmd` 可使用开发工作区中已生成的数据包。独立安装后，从右上角数据包菜单输入本地完整包的目录以安装，再选择快照。
2. 选择全国快照。全国缩放自动由概览切到源几何，点开「视图」可选择主题和精度模式，也可输入经纬度与 Zoom 定位。
3. 左侧目录按线路、站点、设施等筛选，支持中文和拼音检索。点选以后，右面板随地图打开属性。进「OSM 原始对象」可跟踪原始成员。在「工作区」可以保存改名、颜色、线宽和透明度，编辑支持撤销与重做。
4. 「路径分析」中的工作区线路工具支持按成员拆分、对多条源线路合并、浏览结果，物理通道在「运行」中单独保存。
5. 在「运行」建立通道和日期车次，指定时刻及停站锚点，选中实例即可打开运行图。用播放、暂停、倍率、跳时与跟随控制地图车辆与运行图。时刻导入、导出、车辆和 L3 场景位于对应标签页。
6. 「诊断」汇总帧采样、选择响应、属性读取、瓦片生成和缓存。可拖拽地图两边的分隔条或在「视图」收起任意面板。主题、布局和专题开关保存于本机。

整体以地图为主视图，工具用图标配中文标签，焦点可通过 Tab 访问表单和按钮。专用快捷键、面板浮动与跨 DPI 自动测试未覆盖。
