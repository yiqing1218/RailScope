# 分场正线基准与平行出口导出

默认算法为 `yard_centered_parallel_outlets_v4`：各场分别建立自己的正线基准，保留股道之间的相对弯曲，再处理场外接轨和方向。拓扑用于保证现有对象接得上，不决定站内股道的排布形状。“源形状比例（兼容）”保留作对照，逐线、编号、颜色、端口和延长线编辑继续可用。

## 布局与数据分工

| 模块 | 职责 |
| --- | --- |
| extractor / topology | 提取实际站内对象和相连的外围对象；检查真实节点连接，不分配最终形状 |
| yard_classifier / yard_groups | 复用 StationTrack、Yard、线路成员关系；图示调整独立保存，归属冲突保持灰色 |
| yard_selection | 选择分场；排除其他场的站台区域股道，保留实际相连的外围接轨段 |
| station_extent | 找出最后道岔、接轨及不同正线几何交汇；几何交叉不会创建连接节点 |
| yard_reference / yard_layout | 以每场中央正线及实际相连的方向延续作参考，分别消除共同弯曲；站台区水平，咽喉留出更长收束空间，压缩分场间空白 |
| connection_layout | 站场完成后将外围连接整理成统一平滑曲线；保留真实分岔和共用节点 |
| outlet_layout | 对自由区段的弧长分布做一阶方向拟合，分开引出；端口延长线作为独立绘图记录 |
| label_layout | 股道、实体台体、乘降面、分场、正线名称共用文字避让登记表 |
| renderer / export | 同一 SVG 渲染为 SVG、PNG、矢量 PDF，不截图地图 |

“站内 / 站外”是本张图的功能分区，不冒充实际站区多边形。每条正线可以在不同位置结束交汇，不能用一个全局裁切点吞掉较早分离的线路。外部方向参考可设置半径，按几何弧长积分计算，折点密度和普通 edge 切分不会改变方向权重。外围横向大跨度也进行单调压缩，避免把远处实际接轨点裁掉。侧向正线不能因整段拉直而取得穿过台体区的捷径；保持实际接轨节点，连接区使用外围圆角转折，自由区段才拉直。

真实共用节点在图中仍只有一个坐标。按绘图要求，独立线路交叉处保持连续线条，不增加白色断口或小叉；是否相连保存在节点与边的元数据中，不把几何交叉当成道岔。所有修改仅产生图面坐标，测试和示例脚本检查 Repository 与来源几何没有被改写。不生成 Corridor 或调度进路。

提取范围包含咽喉中的短站线和辅助股道，避免仅取正线、联络线而漏掉实际接轨段。出口双线按画面上的顺序排列，并沿用站内中央正线间距；不按原始北向坐标反序。被加载深度或分场选择截断的向内端点，不作为穿越站场的延长线。相同业务线路从同一侧不同方向引出时，端口仍分别保留。

## 分场、颜色与编辑

有明确 Yard 归属的股道按该分场统一颜色；同一业务线路只对应一个图示组时，其连续段沿用该组颜色。多个分场共用的正线不反推某个分场。没有分场资料时只建立已知线路的图示组，并标为“未分场”；未知或冲突归属有导出前提示。默认铁路线宽一致，在建状态仍通过虚线表达。

短站线连续段可沿真实接轨关系使用唯一分场的图示颜色；竞争归属保持待核对。`drawing_inheritance` 明确标记这种显示参考，不补写 Yard、业务线路或运行对象。分场轴线使用的边记录在 `reference_edges` 中，仅作图面依据。

导出布局页新增“导出分场”。虹桥可单独选高速场、综合场；市域线路按现有来源组合为“市域铁路相关股道（来源分场待核对）”，不把组合名称当成已核验分场。单场模式仍显示接到其他业务线路的外围轨道，并提示其他场的站台区域已截断。

保留逐线显示、角色、颜色、宽度、端口文字及偏移编辑，恢复“自动 / 延长 / 不延长”。新增分场样式、逐股道图示分场与编号、台体与乘降面编号编辑；股道可多选后批量设置图示分场。设置单独保存，不覆盖业务归属和运营编号。旧设置迁移后，新版保存的压缩比例和台体宽度能原样恢复。

## 台体、乘降面与编号

实体台体与乘降站台面是两套标注。同一台体可有来源明确的 `8;9`、`8&9` 两个面号，但不能仅因为来源是多边形就自动造出两个乘降面。

- 来源股道号优先显示为“12道”；缺失时保留轨道，不生成 T 序号。人工图示名称继续可用。
- 实体台体有明确编号时使用该编号，否则按横断面顺序显示“台体 1”等本图序号。
- 乘降面使用来源 ref；没有来源编号时标“面号待核对”，不宣称已得到官方面数或编号规则。
- 同一来源对象只标一次；图中新增编号不会写入 TrainRun、StationRoute 或基础设施业务数据。

本实现没有把所有车站套入一个空间排序规则以产生官方乘降面号。可在“站台编号”中补充本图文字，在业务股道编辑中核实真实编号和归属。

股道号、台体号和站台面号缩小显示，共用文字避让登记表。同一分场名称和数量采用两行文字，SVG、PNG、PDF 使用相同排版。数量明确写为“图示 N 台体 / M 股道 / K 站台面”，只统计画到的来源对象，不冒充官方“几台几线”。

## 线路起止资料

共享 China-EMU 资料 653 条线路记录中，642 条具有连续、明确的区间起讫，已补充 `start_terminal` / `end_terminal`。不连续或不明确的记录不拼凑全线终点。旧本地资料在读取时按同样规则补全，原缓存和来源 snapshot 不改写；单区间索引同步支持这两个字段，避免全线与区间索引误报歧义。

InfrastructureLine 复用这两个可选字段。人工资料优先，字段分别保留来源证明；导出元数据包含终点资料及其 provenance。城市 / 车站位置只用于去向判断，不延伸真实铁路。无法定位去向时显示“去向待核对”，可手工填写端口文字。
