# RailScope Next 0.6 设置与地图

从顶部「设置」或 `Ctrl+,` 进入。设置窗口支持关键词搜索和分类恢复默认，调整即时生效并保存在本机。关闭设置后仍停留在原工作台。分类与搜索参考 [VS Code 设置](https://code.visualstudio.com/docs/configure/settings)，地图、显示和数据分组参考 [QGIS 配置](https://docs.qgis.org/4.4/en/docs/user_manual/introduction/qgis_configuration.html)。

| 分类 | 设置内容 |
| --- | --- |
| 地图与底图 | 浅色、彩色、深色或纯交通底图，离线源精度或仅概览 |
| 轨道配色 | 国铁分级或专题配色，城轨按运营线路或轨道类型配色 |
| 图层与标注 | 地表与水域、地名、铁路、城轨、公路及运行图层的预设和显隐 |
| 工作台布局 | 分别设置地图、运行、分析和数据工作台的面板显隐，拖动调整尺寸 |
| 运行与仿真 | 默认仿真层级，和运行面板同步 |
| 本地数据 | 当前使用的快照，以及数据包管理入口 |

地图边上的快捷控件继续用于定位、查看图例和切换图层。运行面板继续控制播放、时钟和当前车次。数据包安装、迁移和审校在数据工作台操作。

- 国铁和城轨默认同时显示铁路分级色与地铁运营线路色。旧版选过「运营线路」的配置自动采用这个组合。原先保存的国铁专题配色继续使用。
- 全国和上海的原始对象版数据包在 Z3–8 增加离线地理参考，从现有快照读取主要水系、道路骨架、行政边界和重点地名。Z9 起，离线源精度使用详细底图。仅含预建概览瓦片的旧包继续使用随包提供的底图。
- 普通国铁站按缩放显示圆形标记。公交场站和缺少铁路来源证据的公共交通站退出国铁站图层。开启「普通兴趣点名」时可查看有名称的公交场站。
