# 运行工作台、加载上限和显示联动修正

日期：2026-10-07

## 使用方式

- 运行侧栏与图层侧栏一样占满地图高度。点击“打开工作台”，国铁或地铁编辑器在独立窗口打开；可拖动、缩放和最大化，关闭窗口不删除计划。
- 通道与车次分别使用左侧方形勾选框，各有总开关。通道关闭只隐藏路径，所属车次仍可显示和运行；选择车次不会重新打开隐藏通道。长通道名称自动换行，保留完整名称提示。
- 运行面板分成仿真控制、目录和编辑操作；补齐定位、保存、导入和导出按钮，地铁与国铁采用相同布局。
- 时间跳转旁新增“跟随北京时间”，使用 UTC+8 的实时日期与时刻，列车按实时 ×1 推进；取消跟随后继续按此前仿真速度运行。手动跳转或重置退出跟随模式。
- 开始运行后，切换面板、隐藏显示、关闭工作台或更新计划不会自动暂停。多个已启动播放器共享一份时钟，切换时钟驱动者不会暂停另一播放器；只有显式暂停停止该播放器，其他仍运行的播放器可继续推进共享时钟。
- 车次标记与车次号位于地图内容的独立堆叠层内，导航、玻璃侧栏与其他操作控件覆盖在其上。
- 工作台新增“车次担当车辆”：选定当前车次、选择同制式的具体车辆、点击“应用担当”。选择“未指定具体车辆”可解除担当。
- 担当保存在独立工作区车辆档案及计划引用中，沿用共享领域 `Vehicle` / `TrainRun.vehicle_id`；允许一辆车担当多个不重叠的车次，拒绝时间冲突和制式不匹配，可撤销、保存和重新载入。
- 车辆档案改成单列车型清单与上下排列的属性 / 值；来源地址保留在提示中，详情自动换行，侧栏没有底部横向滚动条。

## 加载上限

“显示 → 地图元素加载上限”有默认低内存、默认高内存和自定义三种模式。模式与数值独立保存；即使自定义数值等于某个预设，重新打开仍保持自定义。切换到预设后再回自定义，保留此前填写的自定义值。

自定义独立上界为每图层 100000 要素、128 MiB 最终要素 JSON、2000000 顶点，单要素 16 MiB；不再被高内存预设截断。SQLite 扫描范围随自定义元素数调整，避免旧的 24000 行扫描上限使设置失效。四项限制同时生效，并非承诺一定加载到所填元素数量。

## 地图文字

高速公路文字与线路使用相同目录过滤和缩放门槛；取消勾选立即作用于已经加载的数据。车站及控制点文字分别遵守各自开关、目录和显示级别。历史线路的文字与几何统一遵守运营 / 在建开关、目录选择和缩放级别。

底图不再重复显示由可选图层管理的高速、铁路车站、大学和服务区文字。矢量样式请求失败时使用内置简化矢量样式，沿用现有 OpenFreeMap 图源，避免含固定文字的栅格兜底绕过开关。自定义样式用法见 [OpenFreeMap 官方说明](https://openfreemap.org/quick_start/)。在线底图瓦片仍需联网，本地基础设施和计划不依赖在线底图文字。

## 验证

- 与运行窗口、北京时间、车辆、计划、加载上限、地图传输、机场、大学、外观和站内轨道分类相关的 127 项 Python 测试通过；这是所列范围的验证，不是全仓库测试。
- 28 项地图脚本测试通过，包含 MapLibre 样式验证、目录与名称联动、历史显示和加载状态；另行通过车辆动画与公路图层检查。
- SQLite 真实视窗查询可返回 24010 个点，验证自定义设置超过旧扫描上限后确实生效。
- 真实 Windows / QtWebEngine 窗口检查：侧栏 833 像素、地图工作区 857 像素（上下各 12 像素留白）；车辆页横向滚动范围 0；地图脚本错误列表为空。独立窗口另外验证移动、关闭及宽度随窗口变化。
- 最新运行控制检查：地铁、国铁侧栏在 340 像素宽度下均无横向滚动条，长通道名换行完整显示，时间跳转与北京时间选项同排可见。测试覆盖隐藏车次仍推进时钟、通道和车次独立显示、手动跳转不暂停、北京时间跨午夜及播放器时钟接管。
- 真实机场地图检查：轮廓与 POI 联动显示和隐藏；车次号大小及缩放门槛立即生效；侧栏与导航使用同一实时浏览器玻璃背景。车次标记与导航重叠时，导航保持在上方且可点击，地图脚本错误列表为空。
