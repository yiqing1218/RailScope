# 历史、站内运行、车辆与分析工作台

日期：2026-09-30；分支 `codex/rail-history-operations-workbench`。本文件记录本次用户要求、实现边界与验收契约。

## 本次范围

实现 1、4、8、10、11、13、14、19、23。16 按用户后文取消独立车次档案，改为通道档案导出；21、24 按后文暂不新增。其余可行功能仅保留领域服务接口，不显示假数据或已完成状态。

左侧六模块：图层、运行、车辆、分析、编辑、导入导出。保留现有 QAction 与操作实现，各入口复用它们。分析包含通道运行图、跨通道区间统计、站场视图 / 导出和通道档案；对象详情保留全部属性，扩展概览—地图—基础设施—运行—统计—历史统一结构。

## 数据权威与关系

沿用 `railscope.domain` 和 SQLite Repository adapter。原始 OSM / 几何 / 拓扑保持来源层；人工历史、站台关联、车辆及运行引用保存在现有工作区。新增实体有稳定 ID，来源别名仅用于适配与重导入。图片复制到工作区资产目录，数据库只保存资产引用。

- InfrastructureLifecycle → 稳定基础设施 ID；包含建设、开通、停运日期，父线路继承、来源 / 快照 / 核验。未知日期保持未知，不把当代 OSM 等同于历史事实。
- Platform → Station、真实关联 StationTrack；StationTrack → 真实有向 NetworkEdge。
- TrainRun → 完整 Corridor、Vehicle；StopTime → 同一 Station、Platform、StationTrack、StationRoute。
- 车底担当与车站时刻表均从 TrainRun / StopTime 反向派生，不另存一份独立权威时刻表。
- 区间分析从所有完整通道上的真实有向 edge passage 计算，不以名字匹配、不按单个通道分割总体统计。

## 历史时间

搜索框左侧提供“时间回溯”按钮，展开日期 / 年份滑块。无停止日期表示向未来延续；建设到开通为建设期，地图虚线；开通后运营，停运后废止，建设前不显示。当前模式随系统实际日期推进，预设开通日期到达后更新有效状态，不改原始 OSM tags。

线路可以作为成员线段 / 车站的默认时间父对象，单对象显式日期优先。未知历史继续显示并标识未知，不补造日期。当前阶段不虚构迁建前几何；几何版本 / 历史快照接口预留。

历史日历日期与一天内仿真秒是同一 SessionTime 的两个维度；国铁 / 地铁播放器、站场、图表读同一秒值，只有一个播放推进者。跨日用 >24 小时时刻，不把凌晨强行排在前一天。

## 站内细化

Corridor 保持完整连续有向路径。车次 StopTime 的 StationRoute 只在明确的同一站区进 / 出节点之间替换有效运行路径，禁止借此跨线改通道、复制基础设施 geometry 或创建 CorridorSegment。通过车次仍走原通道。

从站台关联的真实股道及已加载站区拓扑求进 / 出路径，尊重方向和可运营状态；自动结果标记 automatic_reference，保留具体边选择并允许人工指定 / 核验。缺失站台关联或真实连通边则 unresolved，不合成直线 / 渡线。停靠位置落在实际指定股道，动画、占用和时刻表共用有效路径。

不统一假设“正线绝不能停靠”；是否邻接站台由实际关联决定。进路图是拓扑 / 时刻参考，不冒充联锁许可。

## 图表、统计与导出

通道图横轴时间，纵轴实际车站 / 里程；停站水平线，上下行区别颜色，导出可调线宽 / 标注字体。同一线路不同有向 Corridor 可在公共物理区段对齐；不按停站列表均匀假设里程。

区间统计匹配真实有向 edge 序列，汇总不同通道车次。时间窗口采用区间进入时刻，边界半开；给出方向、车次前缀、客 / 货 / 未知类型，实际通过数、运行时间、距离加权速度、每小时密度；未知数据不标作零或全网完整。

车站时刻表来自现有导入 / 自建运行计划，按稳定 Station ID 聚合，含到发、停靠 / 通过、股道、站台、进路状态。官方 12306 有 [车站时刻查询](https://kyfw.12306.cn/otn/czxx/init) 与 [车次查询](https://kyfw.12306.cn/otn/queryTrainInfo/init)，查询涉及日期 / 验证码；不将网页当成已获稳定批量 API。复用现有 supplied-12306 / GTFS / CSV adapter，保留公开来源适配接口。

通道档案导出包含地图页和按用户定义的端点—线路序列、完整有向 edge 路径、隐含途经站 / 线路所、来源和核验；地图截图必须来自实际地图，失败显式反馈。站场和图表复用现有 SVG / PNG / PDF 渲染出口。

## 实施顺序与验收

1. 统一领域扩展、SQLite 兼容、时间状态与车辆引用；回归旧工作区无变化、日期边界 / 继承 / 自动开通、车辆担当无重叠。
2. 通道 / 区间 passage 服务、站表 / 档案服务；跨通道、反向、停站、跨夜和空数据测试。
3. 有界 StationRoute 解析与有效运行路径；不改 Corridor，不复制 geometry，方向 / 站区 / 不连通校验；动画停在站台线、占用与站表一致。
4. 历史地图与统一 SessionTime；国铁、地铁、公路及已加载地图表示；未知日期提示，停运 / 建设显示。
5. 车辆编辑、分析 / 站场 / 详情、六模块入口、可调专业导出；实际 Qt 交互测试和截图。
6. 完整回归、独立分支审查、修复及本地中文提交；明确实测范围、数据缺口和预留接口。

不采用一个独立模块一份 JSON 权威副本，不因界面切换重新计算全国数据，不通过关闭功能或降低精度完成任务。
