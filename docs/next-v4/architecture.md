# 0.4.0 地图与运行工作台

## 地图数据与样式

数据包提供只读的 OSM 标签、点线面、物理边与线路成员关系。Rust 的 `cartography::classify` 用相同输入生成精细瓦片分类与对象详情。MapLibre 和图例使用同一份前端符号表。旧 PMTiles 缺少新增字段时使用兼容映射。精细瓦片缓存独立换代，低倍率概览和高倍率源几何仍沿用同一套加载机制。

线路属性、生命周期和车站业务证据单独表示。源数据仅含站台线时绘制线，铁路用地仍按铁路用地显示。图标和线型没有拓扑含义。源标签和稳定 RailScope ID 保存在规范数据包中，用户编辑存入工作区。

## 运行与工作区

通道保存完整有向物理边序列及用户选定的控制端点、线路和区段。预览使用物理图，遇到不连通、逆行或路径歧义时提示用户。自动参考径路的来源和快照随版本保存。车次固定引用一个通道版本。车组和车型由车次独立关联，车组重叠按服务日期和跨日时刻判断。

本次 SQLite 结构增量创建通道归档、上海地铁循环配置和旧版导入审校表。通道编排是原通道载荷的可选字段，已有记录可以继续读取。迁移先校验稳定 ID 或人工映射，失败的文件整批回滚，在「数据 → 审校冲突」保留原因。源对象、时间表草稿和已发布车次各自拥有独立的状态。拖动时刻仅改变草稿，保存时才产生新的车次版本。

地图、运行、分析与诊断、数据共用一张地图。每个模式保留任务面板、对象面板和底部工作区的布局偏好。切模式保留仿真时钟、地图选择与编辑草稿。切换数据包会重新加载当前快照下的对象，未保存的运行草稿需要先处理。
