# RailScope Next 0.4.0 交付与验收

从仓库运行 `Start-RailScope.cmd`，或使用 Tauri 生成的 Windows x64 安装包。安装器和源数据包分别发布。已有工作区可在顶部数据包菜单继续使用原活动快照。

## 旧版功能在新版的位置

| 功能 | 入口 | 当前行为与边界 |
| --- | --- | --- |
| 全国铁路、公路、交通设施和 POI | 地图 → 目录 | 支持中文、拼音和源 ID 搜索、当前视野筛选及原始几何。全国概览可缩放进入精细轨道。 |
| 铁路分类、图例和底图 | 左侧图层或地图上的图层菜单 | 基础设施、运营线路和专题共用图层开关。低倍率旧归档兼容旧分类，源精度层读取可用标签。 |
| 铁路车站、站台、站场和技术设施 | 地图 → 对象属性 | 保留现有实体 ID 和真实几何，新增分类理由与原始来源入口。资料不足时显示待核验。 |
| 业务线路拆分、合并、源成员回查 | 地图 → 对象属性／工作区线路 | 用户改动在工作区版本中保留，可撤销重做。 |
| 共享通道与引用车次 | 运行 → 共享通道 | 按有向物理网络查询端点和接轨线路，支持指定区段、预览、复制、反向、版本保存和归档。 |
| 时刻表、计划车次与运行图 | 运行 → 车次与时刻 → 底部 | 可调整跨日到发时刻、通过、站台和物理锚点。运行图修改进入草稿并可撤销。草稿和已保存位置都按计划时刻计算。 |
| 车型、车组及循环投放 | 运行 → 车辆与交路 | 可分配已有车组、拒绝重叠车次。上海地铁循环由两个有明确锚点的往返模板生成。 |
| 临时径路、资源冲突与系统指标 | 分析与诊断 | 临时路径转到通道编辑器。资源风险可在运行中计算，证据定位按现有快照和数据可用性显示。 |
| 旧运行计划、快照与审校 | 数据 | 支持旧版通道、国铁计划及上海地铁基础时刻字段，无法安全匹配的引用整批回滚，可填映射后重试。 |

## 使用例

地图中选中有实际轨道锚点的车站或物理边，点击「作为通道起点」。运行面板列出可用控制端点。选出发线路并查询可达端点，必要时添加中间行或指定物理区段。预览后保存通道版本，再从该通道新建车次。不同停站方案可以共享同一个通道版本。车组分配和计划回放都沿用同一套运行模型。

窗口内四个模式共用同一张地图。顶栏分别展开左右面板和底部工作区。面板通过边缘拖动调整，布局偏好分模式保存。可以切去查看地图或数据，再返回草稿。切换到其他快照时，程序提示处理未保存草稿。

## 数据与兼容

源对象保留 OSM 标签、原始关系和现有稳定 ID。补充抽取读取已标注的线路所、车场和出入口等设施，缺少源面时保留点或线。上海 v4 已发布到本地数据根目录。全国运行继续使用已通过回归的 v3 源包。全国 v4 全量重建未发布，测试过程中的暂存包已移出数据根目录。0.3.0 的地图快照、计划版本及旧安装包保留，可分别回退。恢复旧二进制时使用升级前的工作区备份。

旧文件的车辆、循环与站内进路引用仍需要人工迁移。当前可用实际轨道证据校验自动参考路径。官方站等、实时列车位置、核验过的联锁进路取决于可用资料。当前数据包没有这些证据时保留未知。诊断中的自动回跳与位置证据仍未覆盖全部冲突类型。站点标签优先级和同站多种几何关系去重仍依赖已有快照覆盖。

## 验证

- Windows x64 发布构建生成 NSIS 安装器。前端类型检查、前端符号 2 项、Rust 核心 10 项、Python 数据管线 4 项和旧版 Python 后端 72 项通过。
- Windows WebView2 离线回归覆盖四模式共用地图、左右独立折叠、1040 CSS 像素与 2× DPR、工作区撤销重做、通道精确区段与跨线衔接、分析结果转为通道草稿、归档后的车次版本引用、旧文件映射重试、草稿位置预览、运行图拖动保存再重启、车组重叠、上海地铁 3 趟方案生成、运行时钟跨模式及 GTFS 导入导出。往返循环的验收使用真实物理边和合成计划时刻、停车锚点。
- 上海 v4 切包通过，设施实体从 5,010 增至 6,515。全国 v3 的济南点位在 Z12.9、Z21、Z22 生成精细瓦片，抽读原 Way 的 42 条节点引用。全国 1 分钟短程漫游零地图错误，零外部请求。
- 复验了 G1 历史时刻示例（670 条物理区段）与上海地铁 1 号线首班重建（38 条区段）的离线运行。两者为拓扑参考用途。
- 本地测试处理 100、500、1,000 趟计划的位置返回，IPC 分别约 10、29、51 ms。长时稳定性和整机内存未测。

### 同场景单次性能抽样

0.3.0 与 0.4.0 使用同一台机器、同一份全国 v3 源包和同一济南 Z21 视野。两次顺序运行时有本地抽取任务并行进行。下表为单次抽样，时间与内存仅用于识别回归线索。

| 指标 | 0.3.0 | 0.4.0 |
| --- | ---: | ---: |
| 从启动调用到首批离线瓦片 | 11.67 s | 10.26 s |
| 全国目录「上海虹桥」平均查询（8 次） | 1.98 s | 2.21 s |
| 6 张 Z21 精细瓦片累计生成耗时 | 145 ms | 164 ms |
| 瓦片缓存增量 | 622,187 字节 | 622,348 字节 |
| WebView 视野内短时帧采样 | 134.5 FPS | 134.6 FPS |
| 切换到运行界面后的双帧耗时 | 15.5 ms | 15.8 ms |
| Rust 主进程工作集 | 39.2 MiB | 41.1 MiB |

可复现入口为 `railscope-next/tests/desktop-smoke.mjs`。本机测试的截图与 JSON 日志位于 `data/logs/next-validation/next-v4/`，源数据和生成物独立保存。
