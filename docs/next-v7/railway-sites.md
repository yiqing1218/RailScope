# 铁路场站

在地图上点场站符号或轮廓，或者从目录搜索名称，可打开右侧对象页。车站、线路所、编组站、车辆段和其他车场共用「概览、关联线路、来源、工作区」。

- 概览显示类别、可用的站码和运营信息，以及站区、铁路用地、站房等源几何。点击「查看精确几何」会定位到点位和已关联的面。
- 同名、类别相容且原始面确实覆盖点位时，轮廓可打开同一个场站对象。同一轮廓包含多个可能的场站点时，保留轮廓自己的对象页。缺少源面时显示点位。原始站台、站房与铁路用地各保留自己的含义。
- 关联线路显示 OSM 业务线路成员、运营线路、同源轨道端点和列车关系。通过轨道几何与场站范围相交找到的线路标注为「几何参考」。
- 来源显示快照、原始标签和 OSM 成员。来源缺少细分类时，可按已有铁路设施的名称给出参考分类。名称、备注和样式修改仍写入工作区。

场站是现有 RailScope 基础设施实体的呈现。关联读取不可变快照，运行继续引用稳定的实体和轨道 ID。地图范围的相交结果用于浏览，通道仍使用有向物理轨道序列。
