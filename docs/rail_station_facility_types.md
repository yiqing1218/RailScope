# 铁路站场类型与目录联动

地图 POI、真实区域、名称标签和车站目录通过同一站场来源记录解析对象。
地图“编辑对象信息”和目录右键“编辑对象信息”共用完整编辑框；双击地图对象展开并选中其目录项。
人工修改仍保存到工作区覆盖层，不修改 OSM 原始标签，也不改变运行对象引用的领域 ID。

## 类型覆盖

- 车站：客运、货运、客货运、编组、区段、中间、会让、越行、工业、港湾、国境、换装、集装箱办理站。
- 所：线路所、信号所、乘降所、动车所、客车整备所、机车整备所、检修所、站修所、列检所。
- 段：动车段、车辆段、客车车辆段、货车车辆段、机务段、机务折返段、工务段、电务段、供电段、综合维修段。
- 场与检修设施：货场、车场、到达场、出发场、到发场、调车场、存车场、整备场、整修站、检修站。

旧工作区中的“动车所/客整所”继续兼容；新识别结果按名称区分动车段、动车所和客车整备所。

## 识别和边界

优先使用具体名称，其次使用明确 OSM 设施标签。`railway=yard` 归为车场，不能仅凭该标签认定编组站。
单一 `railway:yard:purpose` 可提供用途；多个用途并列时保留通用车场类型。
普通社会停车场不能按名称归入铁路车场。尚无明确站型证据的车站保留“未定义”，仍可在目录中编辑。

补查 `railway=service_station`、`railway:facility` 点位和区域，以及没有独立 POI 的真实车场区域。
从真实区域生成的代表点注明 `osm_area_representative_point`；它用于点选和目录定位，不是实测站点坐标。
没有来源的真实面不会被补画。重扫只更新派生站场表示和目录索引，不重建物理轨道段。

## 术语参考

- [清华大学出版社《铁路概论》试读](https://www.tup.tsinghua.edu.cn/upload/books/yz/074529-01.pdf)：车站、区段站、编组站、货运站等分类。
- [国家铁路局《铁路技术管理规程（2006）》](https://www.nra.gov.cn/xxgk/gkml/ztjg/gfzd/bmgz/202206/t20220624_327439.shtml)：机务段、车辆段、客车技术整备所及动车组检修运用基地等历史术语参考，不作为现行规章使用。
- [OSM railway=yard](https://wiki.openstreetmap.org/wiki/Tag:railway%3Dyard)：车场和用途标签。
- [OSM railway=service_station](https://wiki.openstreetmap.org/wiki/Tag:railway%3Dservice_station)：铁路服务设施标签。

类型词表和来源证据帮助补齐当前 OSM 快照，不能证明现实世界中的全部铁路站场均已收录。
