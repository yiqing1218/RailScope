此包是从 OpenStreetMap 提取的上海离线快照。RailScope 选择、分类和索引了原始对象，并生成矢量瓦片。快照日期、输入文件、覆盖范围和 SHA-256 记录在包内的 `manifest.json` 中。

The pack is a Shanghai extract from OpenStreetMap. RailScope selected, classified and indexed source objects and generated vector tiles. The manifest records the snapshot, input, coverage and SHA-256 checksums. GitHub Releases offers the same data as a separate ZIP containing the manifest, SQLite database and PMTiles.
