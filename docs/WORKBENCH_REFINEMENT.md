# 通道、命名与运行显示改进

## 界面判断与改动

原通道窗口的说明文字占用较多空间，站名和接轨线路挤在同一个输入框里，主次按钮的外观接近。输入后容易只看到长文本末尾，也不易判断当前选中的实际对象。

保留浅色铁路工作台风格，以深青色区分主操作。统一中文字体、边框、间距和控件状态；通道名称与编号并排，路径规则折叠，表格交替底色，名称单独显示，完整接轨信息保留在提示中。“应用通道”使用主色。原有增删行、排序、严格模式、手工端点及物理区间功能保留。

使用真实 Qt 窗口检查默认和紧凑尺寸：名称起始文字可见，主操作明确，小窗口可通过表格滚动访问余下行。

## 共性修复

- 搜索编辑文字立即解除旧选择，补全确认会触发联动；候选数量上限在连通和交集过滤之后应用。
- 自动参考路径可沿真实运营轨道跨越线路名称变化处，实际经过的区间、方向和线路完整保存；缺失轨道、停用、未知状态、在建和方向不允许的区间不以虚构连接补齐。
- 工作区覆盖名称同时用于目录、地图线标注和站点标注；已识别站场的未命名股道标为参考名称。
- 车次导入统一处理常见站名写法，利用同一站点的旧名与别名。显示名和物理锚点分开，避免停站显示成“未命名轨道端点”。
- 车辆按实际轨道折点和到发时刻生成短期显示关键帧，浏览器逐帧插值。暂停时停止移动，变速后重新生成关键帧；移动标记独立于地图基础设施数据源，减少标签重新布局和闪烁。
- 人工线路所坐标优先读取节点索引，旧数据统一回退扫描一次，并缓存坐标；重命名只更新文字。
