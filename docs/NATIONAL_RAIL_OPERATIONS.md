# 国铁目录与 G1 参考运行图

## 当前可用功能

- 启动只有底图，地铁、国铁、车站、站台、在建工程、车辆图层全部关闭。
- 全国国铁下载/提取在 **数据源菜单**，不会占据图层侧栏。
- 已有国铁数据在后台升级省级目录，无需重下 PBF。每个轨道段按沿线半长度点落入的省级多边形归类，同名跨省线路分省列出。
- 省界参考数据为 geoBoundaries 2019 年省级多边形，不是权威测绘资料；省界附近/覆盖范围外保持待核对。编辑菜单可以人工调整省份、通道、分段，不修改 OSM 原始属性。
- **运行 → 国铁 · 车次 / 跨线运行图 → 打开 G1 参考运行图**：7 个经停站、可编辑运行表和时间—里程图、开始/暂停/关闭仿真、导入导出。
- G1 小型参考资产随源码提供，不依赖先下载约 1.5 GB 全国 PBF。不会自动启动 G1 或覆盖已保存的用户计划。

先构造一条不往返支线的连通干线路径，再按车站顺序选择该路径上距站点 POI 最近的节点，偏移约 30—633 m，在资产元数据中逐站记录。它们是显示用的站区控制点，不表示真实站台股道，不能因靠近站点就认为已进入该站的正确停靠股道。寻路优先京沪高铁，但未验证上下行方向、道岔可用进路、分配股道、闭塞占用和真实 G1 径路，因此 **只能称“OSM 连通参考径路”，不能称实际调度进路**。

运行图纵轴按几何里程，横轴按到发时刻，停站段体现停留时间。站间位置目前按时间/里程匀速插值，没有实际速度曲线、线路所通过时刻或联锁安全校验。实际运营以当日 12306/铁路公布为准，不得用于真实调度。

## 后续推荐模型：固定基础设施 + 车次区间组合表

用户提出的“固定线路，记录车次跨线端点与时间”适合作为长期模型。下面是设计约定，**不是已经实现的 v2 导入格式**；当前可执行交换格式仍以 OPERATING_PLAN_STANDARD.md 中的 rail-plan.v1 为准。

基础设施表维护稳定的 `line_id`、`section_id`、`from_control_point_id`、`to_control_point_id`、方向、所属线路、真实几何和底层 OSM 区间映射。控制点包括车站、线路所、接轨点等。基础设施版本必须固定，避免数据更新后同一编号含义漂移。

车次区间表每行记录：

`train_id, sequence, section_id, entry_control_point_id, exit_control_point_id, entry_time, exit_time`

另有车次经停表：

`train_id, sequence, station_id, arrival_time, departure_time, platform_id(optional)`

车次按顺序引用已整理的区间，跨线只在已确认连接的控制点发生。列车跨线不是乘客换乘。无需给每辆车重新搜索全国 OSM，但仍需要连续几何供动画显示。

仅有“线路名 + 两端点 + 时间”，在区间路径唯一时足够；遇到支线、联络线、多股道、环线等歧义，必须额外指定 `section_id` 或候选径路，不能悄悄猜测。无法确认的组合应报错并让用户选择，而不是以最近距离连接断点。

到发时间不等于中间每个线路所的真实通过时刻。未提供时可以生成明确标为“估算”的仿真，通过时间、速度曲线、越行与跨线接续等后续能力通过命名空间扩展添加。
