# 国铁车次导入指南

车次表只定义车次在既有完整运行通道上的停站、时刻、站台和到发线，不复制轨道几何，也不会临时拼接通道。

## 操作步骤

1. 先在“运行通道管理”中建立并校验完整、连续、单向的 Corridor。
2. 在“国铁 · 车次运行工作台”点击“导入车次”。
3. 选择 UTF-8 编码的 CSV 文件。整批校验成功后才会写入工作区；任何一行错误都会保留原计划。
4. 导入后在工作台核对停站顺序、到发时刻、站台和到发线，再保存运行计划。

## 最简格式：站名和时间

不需要提前查站点 ID。下面是示例时刻，可直接保存为 UTF-8 CSV 后修改：

```csv
车次,站名,到达时间,出发时间
G9001,南京南,,08:00
G9001,合肥南,09:00,
```

软件会在已有完整通道中匹配站名和顺序，并保存对应站点及站内轨道位置。可省略末尾“站”，忽略空格及全半角差异，也接受常见“火车站 / 高铁站”写法。例如 `福州南`、`福州南站`、`福州火车南站` 和 `福州南火车站` 可匹配同一站。

地图、车站目录、通道和导入共用车站名称表；人工改名优先，原名及有来源依据的别名仍可导入。例如 `绅坊站` 与 `乐清东站` 匹配同一车站，导入后显示当前统一名称。轨道端点和邻近建筑名称不会替代车站名称。

车站属于线路的参考判断同时检查真实轨道段，不再要求站旁必须存在轨道端点。货运站也参与匹配。例如霍邱距阜六线约 48 米，而最近端点约 2.9 公里；现在可以填写 `霍邱` 或 `霍邱站`。中间停站保存共享轨道段上的偏移，不拆分、复制轨道，也不更改完整通道路径。自动投影记录来源、数据版本和“自动参考”状态；不代表已核验的调度进路。

通道编辑框内只显示车站名，框下小字显示接轨线路；长列表悬停可查看完整内容。旧计划中的缓存名称按车站身份刷新，手工自定义通道标题保留。

东、西、南、北等方位仍严格区分；只有相似字形、没有同站别名依据的名称不会自动替换。找不到时提示相近候选供核对。始发站可留空到达时间，终到站可留空出发时间。跨午夜可直接写 `23:28 → 00:04`，软件会按站序把凌晨时刻记为次日；也支持 `24:04` 的明确写法。时钟回退超过 12 小时才自动跨日，较小的时间倒退仍提示核对。

若有多条完整通道符合，错误提示会列出名称；增加 `通道名称` 列指定一条即可。不会在导入时临时拼接路线。同名候选会结合整趟车的前后站序匹配，当前统一站名优先于其他站的旧名。例如 `巢湖` 优先匹配巢湖站，不会因为巢湖西站曾使用这个名称就要求填写节点。只有仍然无法区分的不同车站才需完整名称或编号。

`node_id` 可留空；旧表中的车站标记编号也可转换成通道上的轨道位置。编号失效但站名能够唯一匹配时，按站名恢复，并保留原始输入供追溯。

站序按完整通道的累计行程判断，不按地图方向或某个节点第一次出现的位置判断。支持折返后再次经过同一站、同一轨道；建立通道时将折返点单独填写一行，例如“甲站—线路—乙站—线路—甲站”。车次只引用这条已包含折返的完整通道，不会因为导入表有重复站名就自动添加一条未声明的返回路径。

## 可用字段

| 字段 | 含义 |
|---|---|
| `train_id` | 唯一车次号 |
| `route_name` / `通道名称` | 可选；多个匹配通道时用名称指定 |
| `route_id` | 可选；仍支持旧模板中的完整通道编号 |
| `sequence` / `站序` | 可选；省略时按该车次在文件中的出现顺序，填写时须从 1 连续递增 |
| `stop_name` / `站名` | 停站名称，由软件在通道范围内转换为身份引用 |
| `node_id` | 可选；兼容轨道节点、车站标记编号及同名站消歧 |
| `arrival` / `departure` | `HH:MM:SS` 到发时刻，自动识别跨午夜，也可使用次日 24–47 时 |
| `platform_id` | 可选，真实 OSM 站台 Way 编号 |
| `from_track` / `to_track` / `via_node` / `change_time` | 可选的股道和变道参考字段 |

支持中英文表头；最少四列为 `train_id,stop_name,arrival,departure`。旧版含 `route_id`、`node_id` 的 CSV 继续可导入。名称只用于导入时匹配，保存后仍由身份注册表适配到共享领域的稳定 ID。

点击“帮助 → 下载车次导入模板”生成按名称填写的模板。已有通道但尚无车次时，也能生成起终站模板。请修改示例车次号和时刻后再导入。
