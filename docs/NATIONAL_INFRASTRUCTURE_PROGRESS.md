# 全国铁路基础设施整理记录

本记录对应本地 China PBF 快照，不代表全国现实设施已经在 OSM 完整绘制。

## 真实轮廓

- 真实国铁站台多边形：6,209 个。
- 真实车站站区 / 站房多边形：4,925 个。
- 铁路车站 / halt 源节点：10,580 个，其中 3,652 个节点具有已关联真实面。空间关联仍需复核。
- 高铁分类：5 个源节点明确 highspeed=yes；2,489 个邻近已标注高铁轨道的候选，不能把候选当作已核验高铁站或站台。
- 两个无效 OSM 面对象已记录并跳过，不制造替代形状。
- 全国地铁真实面扩展到 6,700 个，包含站台、站区、建筑；不等于 6,700 个站台。

原始 type/ID、名称、标签、孔洞与多面关系保留。名称是派生显示名，不破坏原始数据。站台、站区、站房独立分类；国铁图层与运行通道复用 source identity。

## 可复用轨道分段

626,851 个实际源轨道区间，按已知端点 / 接轨节点 / 用途变化整理为 403,937 个 RS 分段。已检查：RS 编号唯一、显示名唯一、每个实际源区间恰好归入一个分段。分段含 RL 编号、两端节点、用途、原始分类依据、在建状态、几何长度和底层区间引用。

187,842 个 RL 源身份包括大量未命名的单独轨道对象，**不是 187,842 条官方命名铁路线**。源标签不足的用途不强行猜测；名字可通过编辑菜单改为本地别名，稳定编号不随改名改变。

全国分段目录位于活跃铁路数据目录的 `rail_section_inventory.json`，摘要为 `rail_section_manifest.json`。也可通过文件菜单导出铁路命名与端点分段。命令行重新生成：

```powershell
python -m desktop.rail_inventory --directory "你的活跃铁路数据目录"
```

完整命名和通道表示规则见 `RAIL_LINE_NAMING_AND_CORRIDORS.md`。

## 通道与运行验证

有全国铁路库时，京沪示例从该库重新拼接真实轨道：686 区间，几何长度约 1309.615 km。单独的苏州北—京沪高铁—上海虹桥组合也已解析为 28 个实体区间，不读取旧车次路径缓存、不连接经停站直线。尚未验证真实上下行、股道许可及联锁，不能用于真实调度。

用户新增的上海 2、3、7、8 号线重建计划已校验导入，共 1,381 趟次；逐线验证列车随时刻推进改变位置。9 号线计划含源站序中不存在的“金吉路”，未擅自替换或强行导入。计划为公开资料重建，不是官方调度运行图。

可再生 GIS、原始 PBF 和生成运行计划不提交到 Git；同学需使用文件菜单的下载 / 提取功能获取基础设施。
