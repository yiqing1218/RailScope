# 真实站台轮廓补全策略

1. 先检查显示条件：车站开关、线路目录开关、缩放级别 ≥12。不可将站区或建筑面当作站台。
2. 每次更新按 OSM type + ID 合并旧的真实边界；新快照优先，同 ID 不重复。旧快照保留下来的轮廓带 `retained_previous_snapshot`，可能过时，需人工复核；不会改回老版坐标覆盖新的数据。
3. 同时提取 closed way 和 multipolygon relation，保留多个外环、孔洞、完整原始属性。扩大候选为地铁站、站台、车站建筑。未显式标为地铁的候选仅在关联现有地铁站后纳入，并标注空间派生关联、待复核；明确 train=yes 的国铁面不作为地铁补全。
4. 在「数据源 → 车站真实轮廓覆盖检查」导出清单：有真实站台、仅站区/建筑、无已关联轮廓。站点节点重复不等于多个不同车站，清单保留 OSM 节点供核对。
5. 提取器已读取 stop_area 和地铁路由关系，将明确的站台成员关联到车站节点；这种关系关联不再受原来的 150m 空间阈值限制。清单内仍缺失的站，继续核对 stop_area_group、别名及合法来源；地铁站出口并不是完整站台。可导入有授权来源的官方 GIS/CAD/GeoJSON，不能承诺找全 OSM 尚未绘制的地下站台。
6. OSM 未绘制时，行政边界、商业 POI、卫星影像均不能可靠生成地下站台轮廓。需要人工绘制且保留来源和审核状态；本软件不会用圆圈、凸包或缓冲区假冒真实轮廓。

后台导入失败不会切换活跃数据目录。已有边界只是保持可追溯，不保证旧面仍代表当前车站形状。

## 全国铁路 / 高铁轮廓

全国铁路提取流程现包含真实站台、站区及 train_station 建筑的 closed way 与 multipolygon relation。明确属于地铁站台的关系成员不会混进国铁面集合。站台、站房与站区分层保存，不能互相冒充。

统一显示名为“车站名 · 站台编号 / 车站建筑 / 站区 · way/ID 或 relation/ID”。`source_name`、`way_tags` 和源几何保留；`infrastructure_id` 是原始对象的唯一身份，空间关联的 `station_id=node/ID` 与通道中的站点共用。空间关联标注待复核，不能当作官方站场归属。

覆盖清单同时记录明确 highspeed=yes 的站点、距已标注高铁轨道 1500m 内的候选站点、未判定站点。邻近高铁不证明每个站台都是高铁站台；混合站场尤其需要核对，不能通过“高铁”字样或附近轨道把所有面强制改成高铁。

入口「数据源 → 全国铁路站区 / 站台轮廓覆盖检查」，可导出缺失清单。可再生数据位于活跃铁路数据目录中的 `rail_platforms.geojson`、`rail_station_areas.geojson`、`rail_boundary_manifest.json`、`rail_boundary_coverage.json`；数据库中使用同一身份。全国扫描涵盖当前 PBF 中可取得的真实轮廓，不等于全国现实设施已完整绘制。
