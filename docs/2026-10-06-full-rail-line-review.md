## 修改规则

目录、对象详情和样式使用同一套字段：线的种类、铁路类别、线路功能；高速铁路再对应轨道设计速度范围。运营状态独立保存，在建、规划、停用区段显示虚线。

整线包含不同标准或不同运营状态时，保留区段事实，整线汇总标记差异。点击地图区段后，详情显示该区段的类型、状态和速度范围，并显示分类复查提示及依据链接。

轨道设计速度、线下设计速度和最高运行速度分别处理。局部区段资料不会通过短别名套到整线；缺少统一轨道设计速度时保持“速度范围待核实”。

所有调整写入现有工作区及参考资料覆盖层。原始 OSM、轨道几何、稳定编号、合并成员、车站归属、人工名称和运行对象引用均保留。重复运行应用检查，新增分类修改为 0。

## 后续修改方法

重启 RailScope 加载本次结果。目录中右键查看线路属性，在“国铁线路信息”中修改铁路类别、线路功能、速度范围及运营状态；这些值继续保存到独立工作区。

批量检查使用同一个脚本：

```powershell
cd D:\RailScope
# 生成检查结果，不应用分类或样式修改
python scripts/review_rail_lines.py
# 应用检查结果，并保存修改前的覆盖值
python scripts/review_rail_lines.py --apply
```

官方分类依据保存在 [来源清单](D:/RailScope/data/catalog/rail_line_review_sources.json)，包含适用名称、事实、原文链接和快照。地域性清单检查范围，普速清单不会覆盖明确的货运或工业标签。新增依据需说明其适用整线还是具体区段。

采用的依据包括国家铁路局对 [京广、京九普速线的说明](https://www.nra.gov.cn/tlfc/tpsy/202601/t20260121_350446.shtml)、[浩吉与瓦日货运干线的说明](https://www.nra.gov.cn/xwzx/xwxx/xwlb/202410/t20241008_346969.shtml)，以及 [普速保护区线路表](https://www.nra.gov.cn/zzjg/jgj/syjd/sgsgg/201911/P020220825544637781349.pdf)。China-EMU 页面继续明确标为未核验的外部参考。
