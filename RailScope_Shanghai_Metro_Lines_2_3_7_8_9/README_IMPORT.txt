RailScope 上海地铁多线路公开资料重建包
====================================

目标项目：yiqing1218/RailScope
格式：railscope.operating-plan.v2
线路：2、3、7、8、9号线
性质：公开资料重建，official=false，不是官方ATS/司机运行图。

为什么仍然是“生成器”而不是固定JSON：
RailScope会严格核对本机OSM派生的 station_id 和 distance_m，distance_m 容差只有0.01 m。
不同日期下载的Geofabrik/OSM快照可能使站点节点ID或投影里程变化，因此生成器必须读取你本机
RailScope的 active_dataset 后再输出最终可导入JSON。

使用：
1. RailScope里先完成“数据源 → 自动下载 / 更新全国地铁…”。
2. 把本包中的 generate_railscope_metro_2_3_7_8_9.py 和
   metro_2_3_7_8_9_research_spec.json 放到 RailScope 根目录。
3. 进入 RailScope 根目录运行：
   python generate_railscope_metro_2_3_7_8_9.py
4. 输出目录：
   data/processed/operations/public_reconstruction_batch/
5. 在 RailScope 的地铁运行计划导入菜单中选择生成的 JSON。

默认会生成：
- 每条线一个 weekday 文件；
- 每条线一个 weekend 文件；
- 2/3/7/8/9 五条线合并 weekday 文件；
- 2/3/7/8/9 五条线合并 weekend 文件。

线路处理策略：
2号线：
- 2025-11-01西延伸后，工作日高峰大交路为
  蟠祥路·国家会计学院—浦东1号2号航站楼；
- 小交路为淞虹路—广兰路；
- 早高峰外段约3分45秒、核心约2分30秒；
- 晚高峰外段约4分30秒、核心约3分钟；
- 文件用全程+小交路叠加恢复平均供给密度。

3号线：
- 双向全程约72分钟；
- 工作日早高峰存在方向性间隔；
- 周末公开区分上海南站—长江南路与全程区段；
- 周末文件用全程13分钟+长江南路短交路13分钟错峰，南段约6分30秒。

7号线：
- 已知交路包括美兰湖—花木路、祁华路—花木路；
- 工作日另有上大路—杨高南路；
- 但公开的分段平均间隔不足以唯一恢复逐趟交路排序；
- 因此JSON先输出全程密度基线，完整分段间隔保存在research_spec中。

8号线：
- 全程市光路—沈杜公路约65/66分钟；
- 公开资料显示延吉中路、东方体育中心等区段长期存在不同密度；
- 2019年后夜间小交路组织有调整；
- JSON先输出外段密度基线，不伪造未知逐趟短交路。

9号线：
- 平峰全程上海松江站—曹路；
- 高峰公开交路可较好反推：
  早高峰东行：上海松江站—金吉路 + 佘山—曹路；
  晚高峰：上海松江站—杨高中路 + 佘山—曹路；
- 组合频率可复现公开的核心1分50秒等平均供给密度。

关于4号线：
本批没有硬生成4号线。4号线是闭环线路，而当前RailScope地铁v2计划模型按线性连续
station list校验，一份车次无法自然表达“从宜山路出发绕一圈再回到同一宜山路”而不重复
station_id或人为切车。直接伪造会丢闭环最后一段或产生虚假的中断。更合理的是先给RailScope
增加circular route / wrap-around stop sequence能力，再生成4号线。
